# Download speed test

Консольный Python-скрипт, который оценивает скорость скачивания данных по заданному HTTP- или HTTPS-адресу. Программа последовательно загружает ресурс несколько раз, полностью читает каждый успешный ответ и рассчитывает статистику по фактически полученным байтам.

## Требования

- Python 3.10 или новее;
- доступ к проверяемому URL;
- зависимости из `requirements.txt`.

## Установка

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows команда активации выглядит так:

```powershell
.venv\Scripts\Activate.ps1
```

## Запуск

Стандартный запуск выполняет 10 последовательных запросов с тайм-аутом 30 секунд:

```bash
python speed_test.py https://example.com/large-image.jpg
```

Количество запросов и тайм-аут можно изменить:

```bash
python speed_test.py https://example.com/large-image.jpg --requests 5 --timeout 15
```

Параметры:

- `URL` — обязательный абсолютный адрес со схемой `http://` или `https://`;
- `--requests` — положительное количество последовательных запросов, по умолчанию `10`;
- `--timeout` — положительный тайм-аут HTTP-операций в секундах, по умолчанию `30`.

## Пример вывода

```text
Internet download speed test
URL: https://example.com/large-image.jpg
Requests: 10

[1/10] OK — 2.84 MB in 0.73 s — 3.89 MB/s
[2/10] ERROR — request timed out (30.04 s)
...
[10/10] OK — 2.84 MB in 0.71 s — 4.00 MB/s

Summary
Successful requests: 9/10
Average request time: 0.72 s
Downloaded: 25.56 MB
Average download speed: 3.94 MB/s
```

Ошибка отдельного запроса выводится сразу и не останавливает оставшуюся серию. Если успешно завершился хотя бы один запрос, программа возвращает код `0`; если не завершился ни один — код `1`. Прерывание через `Ctrl+C` завершается коротким сообщением и кодом `130` без traceback.

## Расчёты

Используются десятичные мегабайты:

```text
1 MB = 1 000 000 байт
```

Среднее время успешного запроса:

```text
суммарное время успешных запросов / количество успешных запросов
```

Средняя скорость:

```text
общий объём успешно скачанных данных / суммарное время успешных запросов
```

Неуспешные и частично завершённые загрузки в итоговые объём, время и скорость не включаются. Округление до двух знаков выполняется только при выводе; расчёты используют исходную точность таймера.

## Тестирование

```bash
python -m pytest
```

Тесты подменяют HTTP-ответы и не требуют реального интернет-соединения.

## Известные ограничения

- Результат характеризует скачивание именно выбранного ресурса и зависит от сервера, маршрута, кэшей и повторного использования соединения; это не гарантированная максимальная скорость интернет-канала.
- Запросы выполняются строго последовательно, без потоков и асинхронного параллелизма.
- Значение `--timeout` передаётся библиотеке `requests`: оно ограничивает операции установления соединения и ожидания данных, но не является жёстким дедлайном для полной загрузки большого ответа.
- Тело ответа читается частями и не сохраняется на диск; заголовок `Content-Length` не используется для подсчёта объёма.
- Перенаправления обрабатываются стандартным механизмом `requests`.
